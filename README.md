# BJJ Fitness App

## Overview

The BJJ Fitness App provides users with a central place to log BJJ
training sessions, track weekly progress, review techniques, and manage
fitness and nutrition goals.

## Core Features

- User accounts and profiles
- Training session logging
- Technique library
- Weekly progress tracking
- Nutrition tracking
- Recovery tracking

## Technology Stack

- Flutter / Dart - Mobile application development
- Firebase Authentication - User authentication
- Cloud Firestore - Application database
- Firebase Storage - Profile images and file storage
- GitHub - Version control
- Jira - Agile/Scrum project management

Additional technologies may be added as the application is developed.

## Repository Structure
