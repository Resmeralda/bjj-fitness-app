# Contracts

This folder contains documentation that defines how data is structured and exchanged between different parts of the BJJ Fitness App.

## Purpose

As the application is developed, this folder will be used to document shared data structures and interfaces so that the different parts of the application remain consistent.

Planned documentation may include:

- Cloud Firestore data schemas
- Data models
- Field names and data types
- Required and optional fields
- Interface definitions
- API or service contracts, if applicable

## Planned Data Models

The application is expected to include data models for:

- User profiles
- Training sessions
- Techniques
- Nutrition logs
- Recovery data
- Progress and training goals

These contracts will be defined and updated as the application's design and implementation progress.
